# ASM-DOS

A community-developed operating system based on the Microsoft MS-DOS 2.11 source code.

ASM-DOS aims to modernize and extend the classic DOS architecture while keeping the simplicity, speed, and low-level control of traditional operating systems.

## About

ASM-DOS is a fork based on the MS-DOS 2.11 source code released by Microsoft.

The project focuses on:
- Low-level system development
- Assembly and C programming
- Lightweight computing
- Legacy hardware support
- Learning operating system architecture

## Goals

Future goals of ASM-DOS:

- [ ] Improve the DOS kernel
- [ ] Add new system commands
- [ ] Create a custom shell
- [ ] Improve memory management
- [ ] Add new hardware support
- [ ] Develop new system utilities
- [ ] Create ASM-DOS specific APIs
